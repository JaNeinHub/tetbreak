# TetBreak

Ein kleines Block-Puzzle: Teile auf das 8×8-Feld legen, volle Reihen und Spalten abräumen, den eigenen Highscore knacken.

**Spielen:** einfach die GitHub-Pages-Adresse dieses Repositorys im Handy-Browser öffnen und über das Browser-Menü zum Startbildschirm hinzufügen. Danach läuft das Spiel wie eine App, auch offline.
